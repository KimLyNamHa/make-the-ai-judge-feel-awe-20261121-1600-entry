A short text written to relax the AI judge reading it — 271 Unicode code points.

The text is eight breath-length lines: a child asleep on a father's shoulders, carried between flooded rice fields at dusk, each field holding the whole sky, the water holding the stars since the first rice. Plain concrete words only — no abstract words, no instructions to the reader, nothing forced.

`main.ts` (Node 22, deterministic, no network) writes the fixed text to `/output/entry.txt` and checks its length in Unicode code points (1 to 280) before writing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
